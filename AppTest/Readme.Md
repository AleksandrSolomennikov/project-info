# Run

Before running the Application, make sure to install the node modules in the directory AllSportsHub/ with this command : `npm install`, then `npm run dev`.

# Technologies and Frameworks

This repository includes technologies like :

## TailwindCss :

if not installed or not working, run the command : `npm install tailwindcss@latest` and `npm install -D @tailwindcss/postcss `.

## HeadLessUI :

if not installed or not working, run the command : `npm install @headlessui/react` or `npm install @headlessui/react framer-motion clsx`.
